# Sakina — Product Brief

## One-line concept
Tell the app how you feel; it returns a Name of Allah, one or two Quran verses, and a dua matched to that feeling. Save it, reflect on it, collect it.

## The core loop
1. User opens app → "How are you feeling?" (free-text input OR tap from emotion grid)
2. AI maps the feeling → returns a Name of Allah + 1–2 Quran verses + a dua, drawn only from a pre-verified scholarly dataset (the model never generates scripture)
3. User sees a beautiful, share-worthy result card; can save it to the journal, reflect deeper, or share it
4. Daily streak + collectible cards (Bronze → Silver → Gold → Emerald) pull the user back
5. Build-a-Dua lets users assemble personal duas from verified components

Every feature in the app must serve this loop or retain users around it.

## Why this exists
There is no "Bible Feels for Muslims." Two billion Muslims, zero polished apps that connect emotions to Islamic scripture. Christian equivalents (Hallow, Glorify, Bible Feels) have raised $240M+ combined. Sakina is the wedge into that market.

## Audience
- Muslim, 18–35
- English-speaking
- Primary geos: US, UK, Canada, Australia
- Spans practising lifelong Muslims, returning Muslims, reverts, and culturally Muslim users exploring deeper practice
- Mental-health-aware; comfortable with reflective, journaling-style content; sceptical of preachy religious media

## Brand pillars
- **Gentle** — slow pacing, warm cream backgrounds, soft entrance animations. Never urgent, never aggressive.
- **Spiritually grounded** — every piece of content traces back to Quran, Sunnah, or the 99 Names. Zero invented theology, zero pop-spirituality slop.
- **Reflective** — invites the user inward, doesn't perform outward. Quiet over loud.
- **Never edgy** — no shock hooks, no sarcasm, no in-group dunking on other Muslims or other faiths.
- **Never trendy for the sake of it** — we will skip a trend rather than break tone.
- **Never preachy** — we don't lecture, guilt-trip, or moralise. We hold space.

## Visual identity
- **Palette:** warm cream (`#FBF7F2`), deep emerald (`#1B6B4A`), matte gold (`#C8985E`), near-black ink (`#1A1A2E`). Light mode is the default; dark mode is a warm charcoal not pure black.
- **Typography (marketing/social context):** Lora for editorial body, Aref Ruqaa reserved exclusively for the Name of Allah hero text (decorative naskh). In-app uses DM Serif Display + DM Sans + Amiri for Quran; for TikTok/IG content the Lora + Aref Ruqaa pairing carries the brand.
- **Texture:** Islamic geometric patterns appear at 5–8% opacity as accents only — never busy, never competing with content.
- **Hero element:** Arabic calligraphy is treated as art, displayed large with generous whitespace, not squeezed into a corner.

## What we are NOT
- Not a Quran reader (Muslim Pro owns that)
- Not prayer times / Qibla
- Not a hadith browser
- Not a community/social app
- Not a chat / AI conversation app
- Not a multi-day course platform
- Not a tasbeeh counter

## How this brief informs TikTok research
When evaluating a trend for Sakina:
- Does it map to the core loop? (emotion → Name/verse/dua → reflection)
- Does it respect the brand pillars? (gentle, grounded, reflective, never edgy/preachy)
- Could it be filmed with the visual identity intact? (cream/emerald/gold/ink, generous whitespace, Arabic-as-art)
- Would our actual audience (Muslim 18–35, reflective bent) save it, send it to a friend, or roll their eyes?

If any answer is "no," skip it — even if the trend is hot.
